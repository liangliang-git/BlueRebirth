# Server-local client snapshot

Generated by `tools/export-rust-catalog.ps1`.

- `config/`: full client `config_*.db` snapshot.
- `data/`: canonical Rust server runtime JSON.

The database snapshot is intentionally ignored by Git because it contains roughly 209 MB
of binary configuration. Runtime JSON remains tracked because Rust server behaviour
depends on it. Re-export database files only when client configuration changes.
