# Server catalog

Generated by `tools/export-rust-catalog.ps1` and `tools/build-catalog-db.py`.

- `..\server_config.db`: immutable SQLite catalog artifact used by server at runtime.
- `server-config/`: freshly extracted JSON source used only to rebuild `server_config.db`.
- `data/`: server-owned source data; shops, mails and battle quantity overrides are imported
  into `server_config.db` too.

`server_config.db` uses one readable data table per `config_*.json` source. Each table contains `id`
followed by every top-level key under the source row's `value` as a column, so values can be
inspected directly with SQLite. Arrays and objects remain JSON text in their corresponding
columns. When a source value also contains an `id` key, that column is named `value_id` because
the table's `id` is the row identifier. `catalog_columns` stores type and source-key metadata.
The server opens the database read-only, reconstructs typed catalogs once at startup, then
serves requests from memory.

Rebuild after client configuration changes:

```powershell
python .\tools\build-catalog-db.py --catalog-root .\rust-server\catalog --output .\rust-server\server_config.db
```

Deploy `server_config.db` and the server executable under `客户端补丁\server`.
