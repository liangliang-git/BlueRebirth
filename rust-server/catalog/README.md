# Server-local client snapshot

Generated by `tools/export-rust-catalog.ps1`.

- `config/`: raw server-side `config_*.json` snapshot; legacy `config_*.db` is optional.
- `server-config/`: generated, pruned runtime snapshot. The server prefers this directory
  when `manifest.json` exists, then falls back to `config/` during migration.
- `data/`: canonical Rust server runtime JSON.

Generated catalog snapshots are intentionally ignored by Git because they contain
client-sized configuration data. Rust loaders use JSON only; legacy `.db` files are
not opened. Re-export `server-config/` when client configuration changes.
