# Server-local client snapshot

Generated by `tools/export-rust-catalog.ps1`.

- `config/`: server-consumed `config_*.json` snapshot; legacy `config_*.db` is optional.
- `data/`: canonical Rust server runtime JSON.

The generated catalog snapshot is intentionally ignored by Git because it contains
client-sized configuration data. Rust loaders prefer plain JSON and fall back to the
legacy XOR-encoded SQLite files when JSON is absent. Re-export JSON when client
configuration changes.
